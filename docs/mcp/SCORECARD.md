## Schedule

The eval runs nightly at 02:00 local time via launchd.

Install:

```bash
cp apps/mcp-server/scripts/com.klauro.nightly-eval.plist ~/Library/LaunchAgents/
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.klauro.nightly-eval.plist
```

Uninstall:

```bash
launchctl bootout gui/$(id -u)/com.klauro.nightly-eval
rm ~/Library/LaunchAgents/com.klauro.nightly-eval.plist
```

Verify and run on demand:

```bash
launchctl list | grep com.klauro.nightly-eval
launchctl kickstart gui/$(id -u)/com.klauro.nightly-eval
tail -f /tmp/klauro-nightly-eval/cron.log
```
