# Coordination Fabric v2

This specification is retained only so historical links resolve. Its grant, queue, ownership,
and collision-prevention model is superseded in full by
[Coordination Fabric v3](./SPEC-COORDINATION-FABRIC-V3.md).

Do not implement or describe Fabric from this document. Fabric retains every participant’s
attributed semantic stream, supports realtime collaboration on overlapping work, and treats
duplicate or divergence signals as shared context rather than permission or serialization.
