Key Onboarding Screens

Welcome Screen

Shown when user has no workspaces

  • Large business icon
  • "Welcome to Klauro" heading
  • Value proposition text
  • Prominent CTA button

Create Workspace Modal

First major action for new users

  • Workspace name input
  • Auto-generated slug
  • Description textarea
  • Personal/Organization toggle
  • Private/Internal visibility

Empty Workspace State

Encourages adding first codebase

  • Info alert with guidance
  • "Get Started" button
  • Stats cards (all zeros)

Add Codebase Modal

Connect or upload code

  • Source type tabs
  • Repository URL input
  • Branch selector
  • Analysis settings
  • Notification toggles

Visualization Screens

System Overview

First screen when viewing a codebase

  • System name + type badge
  • Tech Stack (languages, frameworks)
  • Architecture layers breakdown
  • Entry points by type
  • Clickable section cards

Domain/Section View

All endpoints in a domain

  • Back button + breadcrumb
  • Section icon + name
  • Stats (endpoints, auth, db)
  • Capability cards grid

Flow View

Request trace visualization

  • Endpoint header (method + path)
  • Auth status chip
  • Stats (steps, depth, db)
  • Call tree with expand/collapse
  • Bottleneck warnings

Node Detail Panel

Right sidebar, slides in on click

  • Type chip + name
  • Source file + line
  • Documentation/JSDoc
  • Parameters list
  • Incoming/outgoing connections
  • Exit points (db, api)

Graph View

Full architecture diagram

  • Canvas with nodes + edges
  • Zoom/pan controls
  • Layout toggle
  • Filter by type/layer
  • Minimap
  • Search

Patterns View

Design pattern analysis

  • Pattern cards grid
  • Instance counts
  • Deviation warnings
  • Click for details

Call Tree Interaction

flowchart LR subgraph "Call Tree UI" A[Entry Point\nController Method] --> B[Service Call] B --> C[Repository Call] C --> D[Database Exit] B --> E[External API Call] E --> F[HTTP Exit] end subgraph "Node Card" N[Node Type Chip] N2[Node Name] N3[Expand Toggle] N4[Exit Point Icons] end style A fill:#e0234e style B fill:#3949ab style C fill:#00897b style D fill:#7e57c2 style F fill:#ff9800

Each node in the call tree is clickable and opens the detail panel. Nodes are color-coded by type (Controller=red, Service=blue, Repository=teal). Exit points show icons for database, external API, etc.

Billing Tiers

Free

For individuals getting started

  • 3 workspaces
  • 5 codebases per workspace
  • 1 user

Pro

For serious developers

  • Unlimited workspaces
  • 50 codebases per workspace
  • 10 users

Enterprise

For organizations

  • Unlimited everything
  • SSO integration
  • Priority support
