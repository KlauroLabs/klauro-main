# Fabric Fleet Evidence

Fabric’s proof bar is realtime collaboration with retained attributed streams, including overlapping
work. It is not exclusive ownership or collision prevention.

Verified evidence:

- 100 mixed human/agent participants retain every claim and semantic stream.
- Five reconciliation rounds over 500 participant-observations complete with zero merge decisions,
  surprises, or unattributed changes.
- Five deployed two-machine process runs retain every remote claim and extension.
- A sustained Linux run exits cleanly after 179 seconds with loopback claim p95 of 100–129 ms.
- The conceptual fleet proof derives real flow and step coordinates, detects same-step and shared-entity
  relationships, retains both duplicate-intent streams, and treats conceptual groups as shared context.

Run the current conceptual proof from `apps/mcp-server` with `npm run fabric-fleet-proof`.
